  - `/api/v1/x402/services/search` ($0.002)

  - `/api/v1/x402/services/verify` ($0.001)
- Guard: `/api/v1/agent/spend-policy` ($0.001)

## 8-step protocol

1. Client Request  
2. HTTP 402 Challenge  
3. Client signs USDC payment  
4. Auto-retry with `PAYMENT` / `X-PAYMENT`  
5. Facilitator verify (GoPlausible)  
6. USDC settle on Algorand  
7. Tx receipt (`PAYMENT-RESPONSE` + JSON `settlementTransactionId`)  
8. API response (plans + atomic hops + receipts)
